Задача: Создать страницу с профилями сотрудников.

Что нужно сделать в script.js:
1. Создать массив employees из 4 объектов. У каждого объекта есть свойства: name (имя), job (должность), email (почта), avatarLetter (буква для аватара).
2. Написать функцию renderProfiles(data), которая очищает контейнер и создаёт карточки для всех сотрудников.
3. При загрузке страницы отобразить всех сотрудников.
4. Реализовать кнопку "Отсортировать по имени" — при клике сотрудники сортируются в алфавитном порядке и страница обновляется.
5. Реализовать кнопку "Показать только первых двух" — при клике показываются только первые 2 сотрудника из МАССИВА (не удаляя остальных данных).
6. Реализовать кнопку "Сбросить" — показать всех сотрудников снова.

Важно: HTML и CSS менять нельзя. Работаем только в script.js.
